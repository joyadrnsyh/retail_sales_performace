# 📊 Sales Analytics Dashboard – End-to-End Data Analysis

## Overview

This project demonstrates an **end-to-end data analytics workflow**, transforming raw sales transaction data into actionable business insights through **data cleaning, exploratory data analysis (EDA), and interactive dashboard visualization** using Microsoft Power BI.

The dashboard is designed to help stakeholders monitor **sales performance, profitability, customer demographics, product contribution, and geographic market distribution** in a single interactive view.

---

## Project Objectives

The main objectives of this project are to:

* Analyze overall sales performance.
* Measure revenue, profit, cost, and quantity sold.
* Identify monthly and yearly sales trends.
* Understand customer purchasing behavior by age segment.
* Compare sales performance across countries.
* Identify top-performing products based on profit contribution.
* Visualize product category distribution.
* Generate strategic business recommendations based on data insights.

---

## Dataset Information

The dataset contains transactional sales records with key variables such as:

| Feature          | Description                  |
| ---------------- | ---------------------------- |
| Date             | Transaction date             |
| Revenue          | Total sales revenue          |
| Cost             | Operational / product cost   |
| Profit           | Revenue − Cost               |
| Quantity         | Number of products sold      |
| Country          | Customer country             |
| Product          | Product name                 |
| Product Category | Product classification       |
| Customer Age     | Customer age                 |
| Age Group        | Customer segmentation by age |

## Key Findings

### Financial Performance

| Metric         |           Value |
| -------------- | --------------: |
| Total Revenue  |     **$84.83M** |
| Total Profit   |     **$32.05M** |
| Total Cost     |     **$52.78M** |
| Total Quantity | **1.33M Units** |

---

### Business Insights

* Sales peaked in **2015**, reaching nearly **$20M** revenue.
* Monthly sales show strong performance in **mid-year and year-end periods**.
* **United States** is the strongest contributing market.
* **Adults (35–64 years)** represent the highest revenue-generating customer segment.
* Product sales are concentrated in one dominant category (>60% contribution).
* Premium products contribute the highest profit margin.

---

## Business Recommendations

Based on the analysis:

* Prioritize marketing toward **Adult customers (35–64)**.
* Increase market penetration in high-performing countries.
* Prepare inventory ahead of seasonal demand peaks.
* Expand high-margin premium product offerings.
* Improve performance of smaller product categories through targeted promotion.
